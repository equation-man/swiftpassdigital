# SwiftPassDigital
Legacy digital ticketing software for swiftpassdigital platform. 

## Features  
#### Events updates and management
Supports posting and managing of events details.  

#### QR Code  
Supports qr code scanning of tickets.

#### Non reusable tickets  
The tickets are non reusable, can only be used once and cannot be used again when the valid time frame has passed.  

#### Sales dashboard  
Events organizers can visualize their ticket sales in real time. 

#### Email delivery  
Tickets are delivered via email to users after purchase.  

#### Payments processing  
Supports processing of payments with Paystack by default or can be configured to use mpesa Daraja platform. 
Funds are split, where commission is taken and the rest disbursed to the event's organizers bank account, according to the 
payments processor provider's terms.

#### Role based accessed  
Access is of different level, with different capabilities such as sales visualizations, events mutations and bank details mutations are given to 
certain accounts. Standard accounts can just scan tickets but not see critical organization's sales data.
